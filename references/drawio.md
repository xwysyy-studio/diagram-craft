# draw.io 制作要点

用 draw.io 实现 SKILL.md 中确定的构图。以下做法让图保持可编辑、再次打开时稳定，并主要靠空间安排解决走线。

## 对象与分组

- 对象用原生形状（矩形、圆角矩形、椭圆、文档、圆柱等），名称写在形状自身的 label 中。只有箭头旁的标签、区域标题等确实独立的文字才用单独的文本对象。
- 有真实归属关系的成员放进容器：容器的 style 含 `container=1`，或使用自带标题栏的 `swimlane` 形状；成员的 `parent` 指向容器 id，坐标相对容器左上角。移动容器时成员随之移动。不需要折叠按钮时加 `collapsible=0`。只在视觉上叠一个框、成员并不属于它时，编辑后关系会散掉。
- 同一角色的对象复用同一套 style（填充、描边颜色与 `strokeWidth`、圆角、字号、字重、字体），不要逐个手调出略有差别的样式。用脚本或模板生成文件时，把每个角色的 style 定义在一处，看过成图需要调整轻重时整类一起改。文字换行用 `html=1;whiteSpace=wrap;`。
- 模块容器用 `rounded=1`，配合 `arcSize` 控制可见的弧度；需要以固定尺寸控制时加 `absoluteArcSize=1`。只设置圆角开关不能保证成图中看得出圆角。分别定义外层模块和内部节点的样式，描边颜色与所在区域协调，按 SKILL.md 的相对轻重设置边界；共享 style 不意味着所有外框都采用同一种深色粗线。

## 连接线

- 每条线都是 `edge="1"` 的连接线，并设置 `source` 和 `target` 指向两端对象，移动对象时线会重新布线。不要只用坐标画出端点悬空的线，也不要用多段直线或形状拼出线。
- 两端对象对齐时用直线直接连通；确实需要转向时，用 `edgeStyle=orthogonalEdgeStyle` 等原生路由让 draw.io 自动计算路径，只有自动路径确实不合适时才加少量拐点。需要指定从哪条边进出时，用 `exitX`、`exitY`、`entryX`、`entryY` 选择连接位置。
- 折线多或线交叉时，先移动对象、调整分区或阅读方向，再考虑给线加拐点。
- 箭头标签写在连接线自身的 label 上，随线移动。线宽、箭头样式与颜色按关系类型统一。

## 颜色与字号

- 配色按 SKILL.md 的原则为整张图协调设计，在 style 中写明 `fillColor`、`strokeColor`、`fontColor` 等具体色值，让同角色对象复用同一套样式，之后仍能在 draw.io 中直接修改。内部浅白底可由实际背景色与白色混合后写入 `fillColor`，形成半透明覆盖的观感，同时保持文字和边界清楚。取色时看对象实际所在的区域；`swimlane` 的正文底色与标题带可能不同，嵌套与叠放也会改变背景。颜色无论取自格式面板的快捷样式还是自行设定，都以整张成图的观感判断是否合适。
- `fontFamily` 指定的字体需要在渲染的机器上存在，否则会被替换，文字宽度改变后可能溢出容器。优先用常见字体，并在导出图上确认。
- 字号按最终展示宽度换算：最终字号(pt) ≈ 画布字号(px) × 最终图宽(英寸) × 72 ÷ 画布宽度(px)。例如 1600px 宽的画布排成约 7 英寸宽的通栏图时，12px 的字只有约 3.8pt。主要标签在最终尺寸下应接近论文正文的字号。
- 描边粗细用 `strokeWidth` 设置，未写时为 1，并按同一比例缩小：上例中 1px 的线约 0.3pt。线宽和字号、字重、图标大小一起决定对象的分量，按导出图在展示尺寸下的整体观感选择，不预设某个数值。

## 图标、logo 与图片

- 图标、logo 和照片用 `shape=image` 的对象嵌入：把 SVG 或 PNG 转成 base64，写成 `image=data:image/svg+xml,<base64>` 或 `image=data:image/png,<base64>`。draw.io 的 style 用分号分隔，data URI 中省略 `;base64`。需要改图标颜色时，先改 SVG 源码中的颜色再编码。加 `aspect=fixed` 保持比例。
- 最终文件不引用在线图标 URL，避免离线或接口变化后图片丢失。
- draw.io 自带的图形库（`mxgraph.*`）可以使用，前提是和图中其他图标画法一致。
- 在成图旁保存素材清单，记录每个图标或 logo 的来源、版本和许可。

## 导出与检查

- 用可用的 draw.io 渲染方式导出 PNG，以及论文需要的 PDF 或 SVG，然后查看。桌面版命令行示例：`drawio -x -f png -s 2 -b 16 -o out.png diagram.drawio`；macOS 上的可执行文件位于 `draw.io.app/Contents/MacOS/draw.io`。
- 按 SKILL.md 的检查顺序，在实际展示尺寸下看图。没有可用的渲染方式时，说明视觉检查没有完成。
